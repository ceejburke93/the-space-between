# Third-party artwork

KayKit — Forest Nature Pack 1.0 FREE, by Kay Lousberg.

- Creator/source: https://kaylousberg.itch.io/kaykit-forest
- License: CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/
- License: CC0 1.0, linked above. The source bundle's separate license file is not included in the public repository because it contains a named supporter roster.
- Eight selected original glTF models, their binary data and atlas are retained in that folder.
- Game adaptation: atlas colors baked into linear vertex colors; chapter tint, scale and static batching applied. No external CDN dependency at runtime.
- Regenerate `src/scene-assets/kaykit-data.json` using `node tools/assets/bake-kaykit.mjs /path/to/KayKit_Forest_Nature_Pack_1.0_FREE`.

The elemental creatures, habitats and continuous terrain are project-authored.
